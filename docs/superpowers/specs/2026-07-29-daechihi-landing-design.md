## 배경 및 목적

대치하이학원(국어·영어·수학, 초·중·고, 본관/프리미엄관(당산)/목동관)의 공개 마케팅 랜딩페이지. 학부모/예비 원생이 검색을 통해 들어와서 학원의 브랜드 인상을 받고 상담 신청까지 이어지도록 하는 것이 목적.

기존 강사 피드백 트래커(`C:\Users\Dee\Downloads\클로드코드`)는 로그인 게이트가 걸린 내부 관리 도구이므로, 이 랜딩페이지는 **완전히 별도의 프로젝트**로 이 폴더(`대치하이학원-랜딩페이지`)에 만든다.

- 공감학원 스타일 스크린샷 — 히어로, 통계 바, 철학 카드 그리드, 멘토/강사 소개, 원장 소개, 학사일정, 언론보도, 영상 섹션이 한 페이지에 연속 배치된 형태. 이번 프로젝트의 구조적 모델.

## 범위

- 대치하이학원 전체 브랜드(3개 지점 통합) 대상의 **단일 스크롤 랜딩페이지 1개**
- 서브페이지(블로그, 계열별 과목 비교 등) 없음 — 향후 별도 프로젝트로 확장 가능하나 이번 스코프 아님
- 콘텐츠(사진, 실제 통계, 강사 프로필, 후기)는 아직 확정되지 않아 **구조/디자인을 먼저 완성하고 플레이스홀더로 채운 뒤, 실제 데이터로 교체하는 방식**으로 진행

- 순수 정적 HTML/CSS/JS (빌드 도구, 프레임워크 없음)
- 파일 구성: `index.html`, `styles.css`, `script.js`, `/assets`

- 반응형: 모바일 우선 설계, 데스크톱까지 대응

## 디자인 시스템

- 배경: 다크 네이비 `#0b1120`
- 텍스트: 화이트/그레이(`#94a3b8` 보조, `#1e293b` 구분선)
- 포인트 컬러: **그라데이션 골드** (`#f6e2a8 → #c9a24b`, 샴페인 톤) — CSS `background-clip: text`로 헤드라인 강조어/통계 숫자/CTA 버튼에 적용. 플랫 골드가 아닌 그라데이션을 쓰는 이유: 기존 골드+블랙 랜딩페이지에 대한 피로감 해소, 가독성 확보를 위해 단일 플랫 골드보다 화사하게.
- 타이포그래피: Pretendard 산세리프 전체 사용(헤드라인 포함) — 세리프는 기각(무겁고 반응형에 불리)
- 모션: 과하지 않게 — 스크롤 시 섹션 페이드인/슬라이드업, 강사진·원장 사진은 호버 시 살짝 떠오르는 효과(hover-lift) + 클릭 시 확대되는 라이트박스(모달)
- 표시광고법 대응: "100% 합격", "전원 합격 보장" 등 절대적 성과 보장 표현 사용 금지 (기존 blog-profile-setup 메모리의 규칙과 동일하게 적용)

## 섹션 구성 (순서대로)

1. **상단 네비게이션** — 로고 + 메뉴(철학/원장소개/강사소개/일정/지점/상담문의) + 우측 "상담문의" 버튼
2. **히어로** — 브랜드 배지 + 그라데이션 골드 강조 헤드라인 + 서브카피 + CTA 2개(상담신청/커리큘럼 보기)
3. **핵심 숫자 바** — 가로 스탯 3~4개(평균 성적 향상, 만족도, 운영연수, 강좌 규모) — 플레이스홀더 숫자
4. **교육 철학/강점 (6카드 그리드)** — 밀착관리, 시스템 중심 운영, 진심 등 브랜드 키워드 기반 카드
5. **원장 소개** — 사진(플레이스홀더) + 약력/철학 + 주요 실적. 사진 호버-리프트 + 클릭 시 라이트박스
6. **강사진/멘토 소개** — 과목별(국/영/수) 대표 강사 카드. 사진 호버-리프트 + 클릭 시 라이트박스
7. **지점 안내** — 본관/프리미엄관(당산)/목동관 3카드, 지점별 특징 한 줄 + 주소/지도 플레이스홀더
8. **학사일정** — 대치하이학원 자체 연간 일정(개강, 설명회, 방학 등) 캘린더. 타 학교 시험일정 비교는 데이터 부재로 이번 스코프에서 제외
9. **최종 CTA 섹션** — 큰 상담신청 유도 블록
10. **푸터** — 지점별 주소/연락처, 사업자정보 자리
11. **하단 고정 플로팅 바** — 스크롤 내내 따라다니는 카카오톡채널/전화상담/상담신청 버튼
